# Tic-Tac-Toe-game

simple and interactive Tic-Tac-Toe game created as a beginner web development project.

✨ Features
🎯 Two-player gameplay
🔄 Restart game option
🏆 Detects winning combinations
🤝 Detects draws
📱 Simple and responsive interface
🛠️ Technologies Used
python(VS Code)

🎮 How to Play
Player 1 uses X
Player 2 uses O
Players take turns selecting a square.
The first player to get three symbols in a row wins!
